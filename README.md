## 📌 Project Overview

**Mutual Fund Analytics** is a data analytics capstone project focused on organizing, validating, and analyzing mutual fund datasets, with an emphasis on Net Asset Value (NAV) data and data quality.

The project follows a structured analytics workflow covering data ingestion, exploratory inspection, quality checks, API-based NAV retrieval, fund master validation, and preparation for downstream SQL analysis and dashboard development.

The objective is to build a reproducible and well-documented workflow that transforms raw financial datasets into reliable inputs for analysis and reporting.

## 🎯 Project Objectives

- Inspect and understand multiple mutual fund datasets.
- Assess dataset dimensions, column data types, missing values, and duplicate records.
- Retrieve historical NAV data through the MFAPI service.
- Save raw API responses for reproducibility and further processing.
- Validate fund scheme codes against available NAV history.
- Organize the project into a maintainable analytics directory structure.
- Prepare the foundation for SQL analysis, visualizations, and dashboard development.

## 🌐 NAV Data Ingestion

The project uses the MFAPI service to retrieve historical Net Asset Value data for mutual fund schemes.

**API service:** [MFAPI](https://www.mfapi.in/)

The ingestion workflow is designed to:

1. Request NAV history using a scheme code.
2. Check the API response.
3. Convert the returned NAV records into a Pandas DataFrame.
4. Save the retrieved records as CSV files.
5. Make the data available for subsequent validation and analysis.

API retrieval and scheme-code validation should be checked against the actual execution output before treating the results as verified.

## ⚙️ Setup and Execution

### 1. Clone the repository

```bash
git clone https://github.com/ansarishams/Mutual-Fund-Analytics.git
cd Mutual-Fund-Analytics
```

### 2. Create a virtual environment

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Add the source datasets

Place the required source CSV files inside:

```text
data/raw/
```

Use the dataset files provided for the project or otherwise authorized for your use.

### 5. Run the data ingestion and inspection script

```bash
python data_ingestion.py
```

This script inspects CSV files in the raw-data directory and generates a consolidated data-quality summary.

### 6. Fetch NAV data

```bash
python live_nav_fetch.py
```

This script is intended to retrieve NAV data through MFAPI. Successful execution depends on API availability, valid scheme codes, and network access.

### 7. Validate fund codes

```bash
python validate_funds.py
```

This script is intended to compare scheme codes between the fund master and NAV history datasets. Ensure that the column names used in the script match the actual CSV schemas.
